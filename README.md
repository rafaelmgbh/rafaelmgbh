I'm a **Tech Lead at Sulivam Softwares** with 15+ years building production systems. My core is **Python** — Django, FastAPI, and deep Odoo (v15 → v19) ERP customization — with Ruby on Rails and Next.js when the job calls for it. Everything runs on **AWS** with **Docker** and a healthy dose of observability. I care about code that ships, infrastructure that doesn't wake me up at 3 AM, and mentoring devs into ownership.

Based in Brazil 🇧🇷 · Working in English & Portuguese.

## What I do day-to-day

- Lead backend & infra decisions at **Sulivam Softwares** — Python services, Odoo ERP customizations, Rails monoliths, AWS infra, CI/CD.
- Design APIs (Django / FastAPI), optimize queries, debug production incidents, mentor mid-level devs into ownership.
- Run a **homelab** for fun: Docker stacks, Prometheus/Grafana observability, Tailscale mesh, automated restic backups to Backblaze B2.
- Build small tools that scratch real itches — dashboards, monitors, automation around AI tooling (Claude Code, MCP).
