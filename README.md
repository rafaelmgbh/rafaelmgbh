I'm a **Tech Lead at [Sulivam Softwares](https://sulivam.com.br)** and the founder of **[DH Consultoria em TI](https://dhconsultoriaemti.com.br)**, with 5+ years as a developer building production systems. My core is **Python** — FastAPI, Django and deep **Odoo** (v15 → v19) ERP work, including Brazilian fiscal compliance — with Ruby on Rails, Next.js and Angular when the job calls for it. Everything runs on **AWS** and **Docker** with real observability. Lately I spend a lot of time making AI agents useful in day-to-day engineering, not just in demos.

Based in Belo Horizonte, Brazil 🇧🇷 · Working in English & Portuguese.

## 🔭 Now (Oct 2026)

- **Platform templates** — reusable **FastAPI + Angular 21** stack: multiple APIs per EC2 host, webhook-driven CI/CD, 2FA/TOTP, HttpOnly cookie auth, rate limiting, payments (Asaas, PagSeguro) and Mercado Livre integrations.
- **Odoo 17 → 19** — zero-touch deploys (GitHub webhook → deploy → health check → automatic rollback), version migrations and Brazilian fiscal localization (NF-e, NFS-e, SPED).
- **AI-assisted engineering** — MCP servers (Brazilian fiscal APIs, semantic search over my knowledge base), ~40 Claude Code skills for deploys, PR review and task-driven dev loops, and LLM-checked deploy notifications.
- **DH Consultoria em TI** — my own company: Next.js 16 + Drizzle web apps, an Expo (React Native) health app, and fiscal automation (NFS-e).

## 🛠️ Beyond the day job

- **macOS tools in Swift** — [ai-usage-bar](https://github.com/rafaelmgbh/ai-usage-bar) (Claude Code & Codex rate-limit windows in the menu bar), plus Docker and server-status menu bar apps and widgets.
- **Self-hosted VPS** — Uptime Kuma, Beszel, Dozzle, Backrest/restic backups, Tailscale mesh and a custom alert notifier wired into chat.
- **3D printing** — cost calculator and storefront with online payments for a small 3D printing business.
- **Mentoring** — helping mid-level devs grow into ownership.
